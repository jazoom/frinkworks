Message prefixes

/skill:name
Expand a saved skill into the message. Use /skill:scope/name when two skills share a name.
/name
Expand a prompt template. Use /scope/name when two templates share a name.
@path
Reference a file or folder. Selection inserts the path only. It does not upload the file or grant access.
!command
Run a command now in the selected location. The command and output join the model context. No provider connection is needed.
!!command
Run a command now without its output in automatic model context. Other tools can still read the files.

Start an ordinary message with a backslash before / or ! to keep the text literal.

Run must be enabled and the location approved. Commands keep the current approval and consent requirements.
