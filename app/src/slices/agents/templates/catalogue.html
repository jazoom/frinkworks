Where saved agents apply

This catalogue stores reusable agent configurations. It starts no execution and assigns no workflow participant.

An agent configuration contains instructions, requested tools and a model preference. It grants no directory access or execution approval.

Conversation presets are a separate resource. A preset stores settings for ordinary conversations. Ordinary conversation setup does not offer saved agents.
