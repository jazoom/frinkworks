Use existing files

Global prompts are available across projects in both host and sandbox modes. Place each template directly inside this directory:

{{ global_path }}

Example: {{ global_path }}/review.md

Each template is an ordinary Markdown file. The file name without the .md extension supplies the command name. No Frinkworks identifiers or revision fields are required. The composer discovers a copied or saved file on the next lookup without a restart.

Frontmatter is optional. It can carry a description and an argument-hint: 

---
description: Review a change.
argument-hint: <path> [<ref>]
---

Review $1 at ${2:-HEAD}.

To use a prompt in the composer, type /<name> and send the message. The model receives the expanded body instead of the model response to that text. Add arguments after the name, for example /review src/main.rs. Quotes group an argument that contains spaces. There is no shell interpolation.

Supported substitution forms:

  • $1, $2 and later positions
  • $@ or $ARGUMENTS for every argument
  • ${N:-default} for a fallback value
  • ${@:N} and ${@:N:L} for argument ranges

Project prompts belong at <authorised-directory>/.agents/prompts/<name>.md. Frinkworks does not search nested project directories. A work location that needs approval does not expose its prompts. The composer reports the limitation instead of reading an unauthorised file, and it labels each suggestion with its source.

When a global prompt and a project prompt share a name, choose one with /global/<name> for the global prompt or /<directory>/<name> for the project prompt. The composer also lists both and labels each one.
